# AutoVault — Premium Automotive Marketplace Frontend

## Project Overview
**AutoVault** is a modern, luxury used-car marketplace inspired by the design quality and user experience of **Spinny**, featuring a custom brand identity, dark aesthetic, and a signature **3D rotating car carousel**.

## Server URL
Visit [http://localhost:5173](http://localhost:5173) in your browser to view the application.

## Run Manually
```bash
cd C:\AutoVault
node node_modules/vite/bin/vite.js --host 0.0.0.0 --port 5173
```
